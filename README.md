# CEA Scrum Sprint

**Jira | Scrum | Google Apps Script**

[![📂 View Apps Script](https://img.shields.io/badge/📂_View-Apps_Script-03a6a5)](apps-script/)

One real Scrum sprint run on Career Engine App's live backlog in Jira, building a Gmail automation that sorts, logs and saves job-search email. This is a solo adaptation: I hold Product Owner and Scrum Master, and the dev work is paired with Claude the same way all Career Engine App work is.

---

# Project Overview

Every employer response to my job applications used to be printed to PDF, uploaded to Drive and linked into Career Engine App by hand. Responses arriving at a second inbox were easy to miss entirely. Sprint 1 automates the first half of that: sorting job-search email into sub-labels every hour, logging each sorted email to a sheet, and saving responses as PDFs to Drive, with no writes to Career Engine App yet.

The sprint runs Monday 10/12 through Sunday 10/18/2026, tracked in a Jira Free Scrum project, with a review and retro on Monday 10/19. The Apps Script code in `apps-script/` runs outside the Career Engine App repo. Daily standups are posted as Jira comments and kept in `standups.md`.
